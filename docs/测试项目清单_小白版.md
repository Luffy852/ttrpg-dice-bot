# 部署后测试清单（零基础版）

> **照着做，做完一条勾一条。卡住就立刻停下，把看到的截图发我。**
> 不需要懂代码，每步都写了"你应该看到什么"。
> 日期：2026-10-29
>
> **先说明**：大部分计算逻辑我已经在开发环境里自动测过了（796 项，全绿）。
> 所以这份清单**不是让你重新验算**，而是验那些**只有真机才能验的东西**：
> 两个人同时看、断网、手机键盘、口令流程。别把时间花在验算骰子上。

## 准备工作（2 分钟）

- [ ] 记下你的网址：`https://ttrpg-dice-bot.________.workers.dev`
- [ ] 记下你建的房间号：__________
- [ ] 准备**两台设备**：一台电脑 + 一台手机（后面的多人测试要用）

## A 组：最基础的（先只做这些，5 分钟）

### A1 页面打得开
**做**：浏览器打开网址
**应该看到**：一个卡片，有「加入房间」「创建房间」两个标签
- [ ] 通过　　- [ ] 卡住（截图发我）

### A2 能建房间
**做**：点「创建房间」→ 填昵称 → **不勾口令** → 点创建
**应该看到**：进入聊天页，顶栏显示 6 位房间号
- [ ] 通过　　- [ ] 卡住

### A3 能掷骰子
**做**：输入框打 `.r 2d6+3` → 发送
**应该看到**：一条可以点开的骰点消息
- [ ] 通过　　- [ ] 卡住

### A4 明细干净
**做**：点开那条骰点消息
**应该看到**：两颗骰子各是多少 + 合计，**不应该**出现「调整项 +0」
- [ ] 通过　　- [ ] 卡住

> ⚠️ **A1–A4 任何一条卡住，立刻停下，不要再往下做。截图发我。**

---

## B 组：多人实时（**这次最重要的一块**）

### B1 两个人看到的是同一串点数 ★
**做**：
1. 电脑上打开房间（已有）
2. 手机上打开同一个网址 → 点「加入房间」→ 填房间号 → 进入
3. 电脑上发 `.r 2d6+3`
**应该看到**：手机上出现的**两颗骰子的数字，和电脑上逐位一样**（比如电脑是 3 和 5，手机也必须是 3 和 5）

- [ ] 通过　　- [ ] 卡住

> 这是整个产品的立身之本 —— **两端必须是同一份不可篡改的明细**，不是"都成功就行"。

### B2 快不快
**做**：电脑发一条，看手机多久出现
**应该看到**：**1 秒内**出现（正常几百毫秒）
- [ ] 通过　　- [ ] 卡住（如果超过 3 秒，记下来）

### B3 人数显示
**做**：看顶栏房间号旁边的人数
**应该看到**：两人进房显示「2 人」；手机关掉页面后，电脑那边变成「1 人」
- [ ] 通过　　- [ ] 卡住

### B4 刷新能回看
**做**：刷新页面
**应该看到**：历史消息全在，**顺序没变、没有重复出现两次的**
- [ ] 通过　　- [ ] 卡住

### B5 断网重连 ★
**做**：
1. 手机进房间
2. 手机开**飞行模式**，等 10 秒
3. 这期间用电脑发 2～3 条消息
4. 手机关掉飞行模式
**应该看到**：手机自动恢复连接，断网期间电脑发的消息**补回来**，且**没有重复**

- [ ] 通过　　- [ ] 卡住

> 这条必须用真机断网验，开发环境里模拟不出来。

### B6 连点不会掷两次 ★
**做**：连续快速点两次发送（发同样一条 `.r 1d6`）
**应该看到**：只出现**一颗**骰子，不是两颗

- [ ] 通过　　- [ ] 卡住

## C 组：四套规则（只验手感，不用验算）

### C1 切规则有醒目提醒
**做**：发 `.set rule coc`
**应该看到**：一条醒目的系统消息（警示色，写"@全体"），顶栏规则胶囊变成 COC
- [ ] 通过　　- [ ] 卡住

### C2 COC 奖励骰
**做**：依次发
```
.st set 侦查 60
.rc 侦查 +1
```
**应该看到**：十位骰有两颗，没被采用的那颗**划掉**，写明「奖励取低」
- [ ] 通过　　- [ ] 卡住

### C3 匕首心中文说法
**做**：发 `.set rule dh` 然后 `.dh 敏捷 15`
**应该看到**：写的是「希望成功 / 恐惧成功」这类中文说法，**不是**"成功带希望"
- [ ] 通过　　- [ ] 卡住

### C4 物语带调整值
**做**：发 `.set rule fu` 然后 `.fu dex ins 13 +2`
**应该看到**：合计里包含那个 +2
- [ ] 通过　　- [ ] 卡住

### C5 D&D 熟练加值
**做**：
```
.set rule dnd
.st set str 16 dex 14 lv 5
.rc 巧手 15 p
```
**应该看到**：合计 = 骰点 + 敏捷调整 +2 + 熟练 +3
- [ ] 通过　　- [ ] 卡住

### C6 中文输入手感 ★
**做**：**用手机**的中文输入法打 `.rc 巧手`
**应该看到**：打得顺，指令被正确识别
- [ ] 通过　　- [ ] 卡住

> 这条只能在真机中文输入法上验，是最容易被忽略的一条。

## D 组：带口令的房间（**先跳过，等前面的都过了再做**）

> ⚠️ **口令一旦设了就不可修改、不可找回**。忘了 = 这个房间永久进不去。
> 所以这一组**只在你想清楚了之后**再做，做完一定截图。

### D1 创建页的展示够不够醒目 ★
**做**：创建房间 → 勾「给房间加口令」→ 输入 4 位 → 再输一次确认 → 创建
**应该看到**：房间号和口令**分开显示**，并明确写着不可修改不可找回
- [ ] 通过　　- [ ] 卡住
- [ ] **我已经截图保存了**（勾这个很重要）

### D2 用口令能进
**做**：另一个浏览器输入房间号 + 口令
**应该看到**：能进
- [ ] 通过　　- [ ] 卡住

### D3 错口令被挡
**做**：故意输错口令
**应该看到**：进不去，而且**不会**提示你"第几位错了"
- [ ] 通过　　- [ ] 卡住

### D4 换设备要重输
**做**：手机第一次进这个房间
**应该看到**：要输口令
- [ ] 通过　　- [ ] 卡住

### D5 刷新不用重输
**做**：同一个标签页刷新
**应该看到**：不要求重新输
- [ ] 通过　　- [ ] 卡住
